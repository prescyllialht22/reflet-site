Planning

Le type détermine où l'événement apparaît sur le site (Pilates, Danse, Run) et sa couleur de badge. Pour les collaborations (déjeuner MOME, Pilates Reformer DEFINE...), choisissez « Collaboration » et gardez leur nom habituel dans le titre (ex : garder le mot « MOME » ou « DEFINE ») — le site s'occupe automatiquement du reste (places limitées, etc.). N'oubliez pas de cliquer sur « Enregistrer le planning » tout en bas une fois vos modifications terminées : rien n'est sauvegardé avant ça.
